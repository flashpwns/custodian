# Custodian v1.0.0 release notes

**Status: prepared, not released.** The tag and GitHub Release are created only
after the corresponding release PR is merged into main and final validation is
run from that merged commit.

Custodian v1.0.0 establishes a deterministic constitutional simulation framework:

- canonical event history, deterministic ordering, replay, and projections;
- observer-local perception, knowledge, belief, memory, relationships, and plans;
- decisions, action proposals, execution, canonical effects, and Director ticks;
- public sessions, export/restoration, external declarative packs, conformance,
  an official starter, and a neutral Signal Room example.

It does not provide narration, LLM integration, a graphical interface,
multiplayer networking, executable world-pack plugins, a marketplace, or an
official Backrooms pack.

## Upgrade and compatibility

The public package and starter target `custodian@1.0.0` and
`canonical-kernel@v1`. Validate each pack before use. Existing canonical history
is never silently rewritten; use explicit documented migrations or retain the
compatible runtime.

## Post-release verification

1. Verify the annotated `v1.0.0` tag resolves to the merged release commit.
2. Verify the GitHub Release uses these notes.
3. Download the release artifact and inspect its package contents.
4. Run `custodian-conformance` against the starter from an isolated checkout.
5. Do not publish to npm without separate authorization.
