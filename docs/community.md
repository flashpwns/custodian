# Community and GitHub configuration plan

GitHub Discussions has not been configured by this repository change. After it
is enabled, create these categories:

| Category | Description | Answers | Posting policy |
| --- | --- | --- | --- |
| Announcements | Release and maintainer notices. | No | Maintainers only |
| General | Project questions and discussion. | No | Open |
| World-Pack Help | Declarative authoring and conformance support. | Yes | Open |
| Ideas | Proposals before an issue or PR. | No | Open |
| Show Your World Pack | Links to independently maintained packs. | No | Open |
| Architecture and Kernel Development | Constitutional and runtime design. | Yes | Open |

The repository topics are configured as: `deterministic-simulation`, `simulation`,
`role-playing-game`, `worldbuilding`, `game-framework`, `event-sourcing`,
`replay`, `procedural-narrative`, `javascript`, and `open-source`.

Do not add a Discussions link until GitHub confirms Discussions is enabled. The
historic repository name should be renamed to `custodian` by an owner only after
checking existing links, package metadata, and redirects; this change does not
rename the remote automatically.
