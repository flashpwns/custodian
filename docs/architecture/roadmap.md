# Kernel roadmap

Milestones 1–10 establish constitutional domains. Milestone 10.5 converges them
behind canonical events and an objective projection. The next milestone may add
perceptual acquisition only after the convergence readiness gate passes: observer
embodiment, sensors, physical observability, observation/perception records, and
read-only scoped scene projection. Narrative prose remains an adapter concern.

Remaining kernel work after perception is limited to deterministic rule/effect
resolution hardening, world-pack extension compatibility, durable persistence and
migration operations, and replay/invariant hardening. Product UI, LLM rendering,
and unrelated simulation features are outside the constitutional kernel roadmap.
