# Constitutional knowledge model

Custodian models mystery by simulating the entire relevant situation and limiting
each perspective to the information it can actually receive. It never uses an
unmodeled secret as a late narrative convenience.

## The five layers

| Layer | Owner | May contradict objective reality? | Narrative use |
| --- | --- | --- | --- |
| Objective reality | runtime projector | No; it is the resolution authority | Never directly exposed by default |
| Perception | named observer | Yes; sensors and senses can be incomplete | Present as an experience or reading |
| Knowledge | named observer | It can be revised, but must have a valid path | Present as what the observer has learned |
| Belief | named observer | Yes | Present only as attributed interpretation |
| Narrative revelation | renderer/perspective | N/A; it is a permission set | May include only permitted material |

## Information path

An information path records how a source event became available to an observer:
source event, delivery event, recipient, modality, simulation time, and reliability.
A path can produce perception or knowledge. A projector rejects knowledge whose
path is missing, addressed to another observer, or temporally impossible.

## Canon authority

Canon constrains objective adjudication; it does not make a character omniscient.
Each world pack identifies the authority behind a claim (`primary`, `derived`, or
`interpretive`) and its confidence. Runtime events pin the world version that was
used. If canon is ambiguous, the objective projection records the resolved rule or
uncertain condition; narrative cannot erase that uncertainty by asserting an
unearned explanation.

## Perspective boundary

A revelation names one observer and may cite that observer's perception, knowledge,
and beliefs. It cannot cite another observer's private state or directly include
an objective fact. Switching from one revelation to another changes the view only;
both must point at the same objective projection sequence.
