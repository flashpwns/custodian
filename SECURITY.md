# Security Policy

Do not report suspected vulnerabilities in public issues. Send a private report
to the repository maintainers through GitHub's private security-advisory feature
when enabled, or contact the repository owner privately through GitHub.

Include affected Custodian version, reproducible steps, impact, and a minimal
non-sensitive fixture. Do not include private world-pack content, credentials,
or copyrighted source material. Custodian treats pack data as declarative; any
path that executes pack-authored code is a security concern.
